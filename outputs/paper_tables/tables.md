# QMF paper tables

Generated by `python -m qmf.paper.tables` from the raw results in `outputs/results` (rows and E10's bound file; every summary is recomputed in memory by `qmf.analysis.derive`, no stored summary is read). N90 cells: number = first grid point with success >= 0.9; `(a,b]` = reached only at the horizon; `>h` = censored at horizon h.

Grid resolution: N90 and its 90% bootstrap CI are read on a 40-point geometric grid (neighbouring points 1.14-1.44x apart), so most CIs span at most one grid step and some are degenerate (e.g. [1221, 1221]). Interpolated N90 values (`*_interp`: success fraction interpolated linearly in log n between the two grid points around 0.9, with the same bootstrap resamples) resolve within a step. For E1 (`t1_uniform`), `*_fine` columns give N90 measured on points at most 1.03x apart around N90 (E1f: the same trials and draws, decoder evaluated there too). Both are reported alongside; every decision rule uses the grid N90.

Late grid reads: where the trials of a group have different horizons (E1 and P at p0 = 0.005, E3, E7, E9, E11, E12), each trial's checkpoints fall between grid points and the grid reads it at its last checkpoint, so the grid N90 comes late (E1f: fine / grid N90 median 0.64 memoryless, 0.84 vault at p0 = 0.005). Headline numbers use fine values where they exist (`t1_uniform`, `t4_vault_noise`, `t11_bound`); other N90 values in such groups are +-1 grid step.

## t1_uniform

E1: uniform fingerprint, vault vs memoryless (uniform Lagrangian). The grid CIs (*_ci90) are limited by the grid
resolution wherever *_grid_limited is True (endpoints at most one grid step apart; steps 1.14-1.44x). Two finer
estimates are reported alongside; no rule uses them. *_interp: success fraction interpolated in log n between grid
points, with the same bootstrap resamples. *_fine (E1f): the same trials and draws, with the decoder also evaluated
at points at most 1.03x apart in a window around N90, with the same resamples. At p0 = 0.005 the trials of a group
have different horizons, so each trial's own checkpoints fall between grid points; the grid (and *_interp) reads each
trial at its last checkpoint at or below n, which delays N90, and *_fine does not (fine / grid N90, median: 0.64
memoryless, 0.84 vault). At p0 = 0 the checkpoints are the grid and *_fine lies within the *_interp CI in every row.
